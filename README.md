# Lembar Kerja Inovasi ETPD dengan AI

Halaman statis (satu file `index.html`) untuk menyusun prompt inovasi ETPD bertahap. Isian tersimpan di browser pengguna saja (localStorage).

## Deploy ke Vercel
Import repo ini di Vercel. Framework Preset: **Other**, tanpa build command, output directory dibiarkan default.
